# Playbooks

Phase sequences, read by the scheduler: front matter lists the phases (model,
turn cap); each `## <phase>` section is that phase's instructions. Baked
read-only into the office image.

- `standard.md`: new projects (the only mode so far).
- `feature.md`: changes Riggy asks for in a project's room.

Reckless and rigorous modes come in Phase 4.
