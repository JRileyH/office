# Playbooks

Phase sequences, read by the scheduler: front matter lists the phases and their
turn caps; each `## <phase>` section is that phase's instructions. The model and
effort come from the project. Baked read-only into the office image.

- `reckless.md`, `standard.md`, `rigorous.md`: new projects, by mode.
- `feature.md`: changes Riggy asks for in a project's room (any mode).
